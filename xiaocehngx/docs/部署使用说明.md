# 井下环境监测小程序 —— 部署使用说明

## 一、项目结构

```
xiaocehngx/
├── app.js                       # 全局入口：连接模式管理、事件总线挂接
├── app.json                     # 页面路由、tabBar（实时监测/设备连接/历史数据）
├── app.wxss                     # 全局工业风样式（配色规范、通用卡片/按钮）
├── utils/
│   ├── eventBus.js              # 全局事件总线（页面与通信服务解耦）
│   ├── protocol.js              # 数据协议解析（BLE/MQTT 双解析函数、半包拼接、容错）
│   ├── store.js                 # 本地存储（30条历史、阈值、MQTT配置持久化）
│   ├── bleService.js            # BLE 蓝牙服务（扫描/连接/notify 订阅/断线提示）
│   ├── mqttService.js           # MQTT 服务（连接/订阅/断线重连/心跳保活）
│   ├── cloudPoll.js             # 华为云影子轮询服务（每 5 秒拉取设备影子并广播）
│   ├── huaweiCloud.js           # 华为云 IoTDA REST 封装（IAM Token/设备/影子/下发消息）
│   └── mqtt.min.js              # MQTT.js 4.3.7 UMD 构建（内置 wx.connectSocket 适配）
├── pages/
│   ├── index/                   # 实时监测页（4 数据卡片 + 阈值设置 + 告警弹窗）
│   ├── connect/                 # 设备连接页（BLE/MQTT/华为云 三通道，互斥切换）
│   ├── history/                 # 历史数据页（最近 30 条，下拉刷新、一键清空）
│   └── cloud/                   # 华为云配置与调试页（账号/设备/影子/下发消息）
└── docs/                        # 本说明文档 + STM32 数据上报协议
```

## 二、开发环境部署

1. **安装微信开发者工具**
   下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

2. **导入项目**
   - 打开微信开发者工具 → 导入项目 → 选择本目录 `D:\xiaocehngx`
   - AppID 已在 `project.config.json` 中配置；如需换用自己的，
     修改 `project.config.json` 里的 `"appid"` 字段（测试阶段也可选择"测试号"）

3. **无需 npm 构建**
   MQTT 库（`utils/mqtt.min.js`，即 MQTT.js 的微信小程序方案，
   社区亦称 mqtt-miniprogram 方案）已直接内置于 `utils/` 目录，
   通过 CommonJS `require` 引入，**不需要**执行"构建 npm"。

4. **真机调试（强烈建议）**
   - 蓝牙 BLE 与 WebSocket（MQTT）能力在模拟器中支持有限，请使用
     "预览"/"真机调试"扫描二维码在手机上测试。
   - 首次使用蓝牙时手机会弹出蓝牙授权，请允许；
     若误拒绝：微信 → 设置 → 隐私 → 蓝牙，重新开启本小程序的权限。

## 三、MQTT 服务器准备

小程序通过 **MQTT over WebSocket** 连接服务器，端口与普通 TCP 1883 端口不同：

| Broker | WebSocket 端口 | 连接路径 |
|---|---|---|
| EMQX | 8083 (ws) / 8084 (wss) | `/mqtt` |
| Mosquitto | 需配置 `listener` + `websockets` | 自定义 |
| 公共测试服务器 broker.emqx.io | 8083 / 8084 | `/mqtt` |

**注意事项：**

- 小程序正式版要求 **域名 + HTTPS（wss）**，需在微信公众平台
  "开发管理 → 开发设置 → 服务器域名" 中把 MQTT 服务器域名加入
  **socket 合法域名**列表（协议选 wss）。
- 开发阶段可在开发者工具右上角"详情 → 本地设置"勾选
  **"不校验合法域名"**，使用 ws 或 IP 直连调试。
- 填写示例（连接页 MQTT 面板）：
  - 服务器地址：`broker.emqx.io`（不要带 ws:// 前缀）
  - 端口：`8083`
  - 订阅主题：`mine/env/up`（与 STM32 发布主题一致）

### 华为云（IoTDA 设备影子）通道（可选）

当 STM32 接入的是**华为云 IoTDA**（属性上报到 `$oc/devices/.../sys/properties/report`）
时，小程序**不能**像公共 broker 那样订阅该上报主题拿到数据（IoTDA 不允许跨设备
订阅、同设备只允许一个 MQTT 长连接、属性上报不向其他订阅者广播）。正确做法是
「设备连接 → 华为云」页启动**影子轮询**：

1. 在「设备连接 → 华为云」面板直接填写参数（与「华为云」Tab 页共用同一份配置）：
   - IAM 账号（账号名 / 用户名 / 密码，用于换取项目级 Token）
   - IoTDA **应用侧**接入地址 `iotda-app`（不是设备侧 `iotda-device` 域名）
   - 项目 ID（projectId）与设备 ID（deviceId，须与 STM32 上报的设备一致）
2. 点「测试拉取」验证：成功表示参数正确且影子里有数据，状态栏会显示最新
   temp/humi/gas；失败按提示排查（影子为空 = 设备离线或上报与产品模型不匹配，
   可到「华为云」Tab 用消息跟踪/设备影子进一步排查）。
3. 点「开始轮询」：小程序每 5 秒拉取一次设备影子，
   解析出最新一帧数据注入实时监测页（与 BLE/MQTT 共用同一套显示/历史/告警链路）。
4. 正式发布前，把下列域名加入微信公众平台 **request 合法域名**（开发期可在
   开发者工具勾选"不校验合法域名"）：
   - `https://iam.cn-north-4.myhuaweicloud.com`
   - `https://<你的接入点>.st1.iotda-app.cn-north-4.myhuaweicloud.com`

> 「华为云」Tab 页保留为高级调试工具：设备列表管理、查询设备影子、
> 下发消息（云 → 设备）等，参数与连接页双向同步。

> 注：STM32 侧若沿用注释里「华为云」设备三元组（ClientID `设备ID_0_0_时间戳` +
> HMAC 密码），其上报的数据会实时写入该设备影子，本通道即可直接取用。

## 四、使用流程

1. **连接设备**（底部 Tab「设备连接」）
   - **蓝牙模式**：点击「开始扫描」→ 从列表点击 STM32 设备名 → 连接成功后
     顶部显示"已连接"，数据自动接收；10 秒无操作自动停止扫描。
   - **MQTT 模式**：填写服务器地址/端口/订阅主题 → 点击「连接」；
     配置会自动保存，下次进入自动回填。
   - **华为云模式**：在本页「华为云」面板直接填写 IAM 账号 / IoT 接入地址 /
     项目ID / 设备ID → 点「测试拉取」确认有数据 → 点「开始轮询」即可自动取数。
   - 三种模式**互斥**：切换模式或连接新通道时会自动断开另一通道。
2. **实时监测**（底部 Tab「实时监测」）
   - 4 个卡片实时显示温度(℃)、湿度(%RH)、有害气体(ppm)、井下状态；
   - 状态正常显示绿色，危险告警显示红色（卡片同步红框）；
   - 气体卡片下方显示当前告警阈值，可在「阈值设置」卡片中修改并保存；
   - **气体超过阈值 或 status=1** 时：长震动 + 弹窗告警（10 秒节流防骚扰）。
3. **历史数据**（底部 Tab「历史数据」）
   - 自动保存最近 **30 条** 记录（时间倒序）；
   - 支持下拉刷新、一键清空（带二次确认）。

## 五、蓝牙模块 UUID 适配

默认按 **BLE UART 透传模块（JDY-31 / HC-08 / 透传类固件）** 约定：

- 服务 UUID：`FFE0`
- 通知特征 UUID：`FFE1`

如果你的蓝牙模块 UUID 不同（如 Nordic UART 服务），修改
`utils/bleService.js` 顶部两个常量即可：

```js
const SERVICE_UUID = '0000FFE0-0000-1000-8000-00805F9B34FB'
const CHAR_UUID    = '0000FFE1-0000-1000-8000-00805F9B34FB'
```

例如 Nordic UART（NUS）：

```js
const SERVICE_UUID = '6E400001-B5A3-F393-E0A9-E50E24DCCA9E'
const CHAR_UUID    = '6E400003-B5A3-F393-E0A9-E50E24DCCA9E' // RX notify
```

## 六、常见问题（FAQ）

| 现象 | 原因与处理 |
|---|---|
| 扫描不到设备 | ① 手机蓝牙未开/未授权；② 设备未上电；③ 设备广播未带名称（本程序过滤无名设备）；④ Android 部分机型需开启定位权限 |
| 连接后无数据 | ① 检查设备固件是否往 FFE1 特征发 notify 数据；② 数据格式是否符合 JSON 协议（见协议文档）；③ 拉近距离重试 |
| MQTT 连接失败 | ① 地址/端口错误（注意 WebSocket 端口不是 1883）；② 未勾选"不校验合法域名"（开发期）；③ 服务器未开启 WebSocket 监听 |
| MQTT 频繁掉线重连 | keepalive 心跳 30 秒；若手机息屏被系统断网属正常，回前台后会自动重连 |
| 华为云轮询启动失败 | 华为云配置不完整：IAM 账号 / projectId / deviceId / IoT 接入地址（须为完整 https 的真实 iotda-app 域名，不能是示例 xxx 域名）；在连接页「华为云」面板补全后重试 |
| 华为云轮询报"影子为空" | 设备离线或从未成功上报；请在华为云控制台用"消息跟踪"确认属性上报是否被产品模型拒绝（服务 ID 应为 show，属性须含 temp/humi/gas） |
| 华为云轮询报"HTTP 401/403" | IAM 账号或权限问题：检查密码是否正确、子用户是否有 IoTDA 访问权限；Token 失效会自动重新获取 |
| 数据偶尔丢失/不刷新 | 解析层对不合法数据会整条丢弃（容错），属预期行为；连续丢失请检查设备上报内容 |
